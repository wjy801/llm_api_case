# P0 迭代四报告与影子门禁代码变更记录

## 1. 变更目标

执行 `dev_plan/P0迭代四报告与影子门禁详细开发方案.md`，把迭代三的 merged 质量事实集转换为稳定、可回放、可解释的报告和影子门禁结论，并接入 `run_master.py` 与 Jenkins Real Smoke 流程。

本次实现遵守两个核心约束：

- 报告只消费 manifest 为 complete、run_id/schema 匹配且全部 output hash 校验通过的 merged 快照。
- 报告或门禁异常必须 fail-open，不改变 pytest、run_master 或 Jenkins 的原退出结果。

## 2. 核心实现

### 2.1 报告与影子门禁

- 新增 `quality/gate.py`：
  - 定义 `p0-shadow-gate.v1` 规则集。
  - 支持完整性、失败分类、HTTP 5xx 比例、超时比例规则。
  - 输出 `PASS/WARN/BLOCK/NO_DATA`，请求比例规则保留 `sample_size`。
  - 小样本输出 `NO_DATA`，不会直接判定通过或阻断。
- 新增 `quality/report.py`：
  - 校验 manifest 状态、run_id、schema_version、输出文件和 SHA-256。
  - 用现有 Pydantic 模型读取 merged JSONL。
  - 按唯一 `invocation_id` 折叠 setup/call/teardown，生成 `QualitySummary`。
  - 汇总失败 occurrence、问题指纹、受影响 invocation/case、owner domain、confidence。
  - 汇总请求成功率、5xx、超时和接口级风险。
  - 原子写出 `summary.json`、`gate-report.json`、`gate-report.md`。
  - 输入缺失或不可信时仍尽力生成 overall 为 `NO_DATA` 的最小报告。

### 2.2 配置与 CLI

- 扩展 `quality/config.py`，新增：
  - `QUALITY_SHADOW_GATE`
  - `QUALITY_MIN_REQUEST_SAMPLES`
  - `QUALITY_HTTP_5XX_WARN_RATE`
  - `QUALITY_TIMEOUT_WARN_RATE`
- 新增统一的 `QualityReportConfig` 和配置校验，比例范围固定为 `[0, 1]`，样本量不得小于 0。
- 扩展 `quality.cli`，新增 `report` 子命令及阈值参数。
- 配置优先级固定为“CLI 参数 > 环境变量 > 默认值”。
- CLI 成功生成报告时返回 0，不使用影子门禁结论改变工具退出码。
- `--no-shadow-gate` 仍生成固定路径的 gate report，并标记为 disabled/`NO_DATA`。
- `quality/__init__.py` 导出新配置、报告和门禁公开 API。

### 2.3 run_master 接入

- `_finalize_quality_run()` 调整为：
  - merge merged 事实集。
  - 写最终 `run.json`。
  - 调用 `generate_quality_report()`。
- merge、run 元数据写入、report 分段容错。
- report 配置非法时输出 warning 并回退默认配置。
- report 生成异常只输出 `Quality report failed open`，不覆盖 pytest 返回值以及 `KeyboardInterrupt/SystemExit` 等原异常。

### 2.4 Jenkins 接入

- Real Smoke 阶段启用质量采集、报告与影子门禁环境变量。
- 复用既有 `reports/**` artifact 归档，不增加重复归档规则。
- 邮件新增：
  - 影子门禁 overall 和完整性状态。
  - 用例失败/错误/跳过摘要。
  - 产品缺陷、配置问题、框架缺陷、未知失败数。
  - 请求总数、HTTP 5xx 和超时数。
  - `gate-report.md` artifact 链接。
- summary/gate 文件缺失或 JSON 损坏时捕获异常，邮件继续发送并展示“质量摘要未生成”。

## 3. 测试变更

- 新增 `tests/quality/test_quality_gate.py`：覆盖 `PASS/WARN/BLOCK/NO_DATA`、失败分类和请求样本量规则。
- 新增 `tests/quality/test_quality_report.py`：覆盖可信快照、hash 不一致、phase 折叠、模型反序列化、小样本和 Markdown 产物。
- 新增 `tests/quality/test_quality_jenkinsfile.py`：静态验证 Real Smoke 环境变量、容错读取和 artifact 链接。
- 扩展 CLI、配置和 run_master 测试，覆盖配置优先级、非法参数、关闭门禁、自动 report 和 fail-open。

## 5. 产物与回退

运行 Real Smoke 后预期生成：

```text
reports/quality/summary.json
reports/quality/gate-report.json
reports/quality/gate-report.md
```

回退开关：

- `QUALITY_ENABLE=0`：关闭整条 P0 质量链路。
- `QUALITY_SHADOW_GATE=0`：保留 summary，关闭影子门禁判断。
