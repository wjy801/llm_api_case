# 质量报告清理阶段 2：删除 P1 观察报告代码变更记录

## 目标

删除 P1 Observation Report 的模型、生成、渲染、配置、CLI、编排和外部链接，保留 Metrics、Semantic、Flaky 及质量事实归并链。

## 代码改动

- 删除 `quality/observation_models.py` 与 `quality/observation_report/**`。
- 删除 `run_orchestration/quality_observation_stage.py` 及流水线中的 P1 stage 调用。
- 删除 `QUALITY_P1_REPORT_ENABLE`、P1 Runtime Config 字段及环境规范化残留参数。
- 删除 `p1-report` CLI 命令和 `quality` 包的 P1 公开导出。
- 删除 Jenkins P1 开关、邮件链接、摘要详细证据链接及 `.env.example` 配置。
- 删除 P1 专属测试和 `observation_refactor` fixture，更新编排边界文件清单。
- 增加 CLI、Jenkins 和运行环境对已删除 P1 入口的反向断言。

## 保留边界

- Flaky 的 Case observation、`build_observation_id`、`fold_case_observations` 等历史事实语义完整保留。
- `quality/flaky.py`、`quality/flaky_importer.py`、`quality/flaky_models.py`、`quality/flaky_store/**` 未缩减。
- Metrics、Semantic、JUnit、Allure 和 P0 事实归并链未在本阶段删除。
- 阶段 0 fixture 中的旧 P1 文件名仅作为历史产物清理验收证据保留，不参与运行时生成。
