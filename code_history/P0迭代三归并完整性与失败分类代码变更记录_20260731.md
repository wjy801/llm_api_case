## 核心能力

- 新增 `write_jsonl_atomic()`，用于 merged JSONL 原子输出。
- 新增 JUnit parser，读取 `quality_case_id`、`quality_invocation_id`、状态、异常类型、脱敏消息和断言位置。
- pytest 插件为 JUnit testcase 注入质量身份 property，不要求业务用例手写 `record_property`。
- 新增确定性失败分类器，支持 `CONFIGURATION`、`FRAMEWORK_DEFECT`、`ENVIRONMENT`、`TEST_DEFECT`、`TRANSIENT`、`PRODUCT_DEFECT`、`UNKNOWN`。
- 新增 aggregator，支持当前 run 过滤、逐行 JSONL 容错、模型重校验、去重、冲突检测、JUnit 对账、失败分类、CaseResult.failure_id 回填和 merged 产物输出。
- 新增 `merged/manifest.json`，记录 merge、classifier、fingerprint 版本、source shard 统计、JUnit 文件、输出计数和输出 hash。
- 新增 `python -m quality.cli merge` 手工归并入口。
- `run_master.py` 在 `QUALITY_ENABLE=1` 时默认补充 JUnit 路径，初始化 `run.json`，并在阶段结束或异常路径中 fail-open 调用 merge。
- 保持 pytest 原退出码和原异常语义；质量归并异常不会替换测试结果。

## 关键边界

- 未修改 `quality.v1` 已冻结模型字段。
- 未实现迭代四的 `summary.json`、`gate-report.json`、`gate-report.md`。
- 未修改 Jenkinsfile。
- 未实现历史基线、Flaky 状态机或强制门禁。
- 不通过 JUnit `classname/name` 猜测用例身份；缺少 quality property 时写完整性问题。
- FailureRecord 按 occurrence 保留，`failure_id` 只作为同类失败聚合键。
