# 质量报告清理阶段 3：删除 P0 门禁报告代码变更记录

## 目标

删除 P0 Gate/Report 的规则、模型、配置、CLI、渲染和外部入口，仅保留可信质量事实归并，并确保 `reports/pipeline-summary.md` 不再读取或链接 P0/P1 产物。

## 代码改动

- 删除 `quality/gate.py`、`quality/report.py` 及其专属测试。
- 将 `run_orchestration/quality_p0_stage.py` 收敛并重命名为 `quality_fact_merge_stage.py`。
- 将编排入口改为 `merge_quality_facts()`，返回明确的 `QualityMergeResult | None`，删除独立报告生成阶段。
- 删除 Gate 阈值环境变量、默认值、`QualityReportConfig` 和报告配置解析逻辑。
- 删除 `GateDecision`、`GateMode`、`GateResult`、`GateRuleDecision`、`QualitySummary`。
- 删除 `report` CLI 命令、报告参数覆盖逻辑及 `quality` 包中的 Gate/Report 公开导出。
- 删除 Jenkins Gate 环境变量和 P0 邮件链接。
- 删除流水线摘要中的 P0 详细证据章节；质量阶段继续使用中性的运行身份与归并事实语义。
- 更新运行编排、配置、模型、CLI、Jenkins、Pipeline Reporting、Metrics/Flaky 相关测试契约。
- 新增 `test_removed_quality_report_boundaries.py`，固定模块、API、CLI、编排、Jenkins、摘要和产物否定边界。
