## 修订内容

- 增加 `.env`/进程环境中的 Pipeline 摘要生成开关。
- 增加 Jenkins 同名 boolean 参数，默认开启。
- 明确 Jenkins 参数/进程环境优先于 `.env`，未配置时默认开启。
- 开关开启时生成主报告，并在失败时尝试最小兜底报告。
- 开关关闭时不生成主报告和兜底报告，也不在邮件中产生摘要链接。
- 开关只控制 `pipeline-summary.md`，不影响 JUnit、Allure、P0、P1 和 Flaky 产物。
- 非法环境值产生明确配置错误，但不覆盖 Jenkins 原始结果。
- 每日真实 Smoke 参数化任务显式开启摘要。
