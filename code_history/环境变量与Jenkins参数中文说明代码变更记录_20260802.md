# 环境变量与 Jenkins 参数中文说明代码变更记录

## 变更目标

将配置入口的英文说明改为中文，使本地 `.env` 配置和 Jenkins 构建参数可以直接判断用途、风险与默认行为，同时保持变量名、默认值和执行逻辑不变。

## 第一性原理与约束

配置说明的价值是降低误操作概率。当前约束是变量契约已经稳定，因此本轮只修改展示文本，不修改取值语义、优先级或 Pipeline 行为。

## 修改内容

- `.env.example`：按运行环境、账号、超时、报告和 P1 观测能力增加中文分组说明。
- `Jenkinsfile`：8 个构建参数全部改为中文说明，并明确真实 Smoke 费用风险、摘要产物路径和并发选项。
- `tests/quality/test_quality_jenkinsfile.py`：增加 Jenkins 参数中文说明的静态回归测试。
- `README.md`、`FRAMEWORK_TEST_SPEC.md`：同步全量离线回归基线为 `606 passed`。

## 不变内容

- 环境变量和 Jenkins 参数名称不变。
- 默认值、可选值和配置优先级不变。
- 流水线执行、报告生成和邮件发送逻辑不变。
- 未执行真实付费接口。
