# 流水线执行摘要移除 Smoke 专属展示字段代码变更记录

## 变更目标

`pipeline-summary.md` 面向整轮 Jenkins Pipeline，不应让 framework-only、collect-only 等构建看起来像一份仅服务于 Smoke 的报告。本轮将用户可见字段统一为通用测试语义，底层参数和产物契约保持兼容。

## 第一性原理与 TOC 约束

报告的主语应是“一次流水线执行”，阶段只是本轮选择的组成部分。原先直接展示 `RUN_REAL_SMOKE`、`SMOKE_TARGET`、`Smoke 收集` 等内部词汇，导致报告定位被单一阶段绑架。当前约束是展示契约，而不是采集或执行能力，因此只调整渲染层和阶段显示名。

## 修改内容

- 执行参数表使用“框架测试、用例收集、接口测试、测试目标、并发配置”等中文通用字段。
- 仅在接口测试启用时展示测试目标，避免其他构建出现无效的 `module/smoke` 默认值。
- 阶段和章节中的“Smoke 收集”“真实 Smoke”分别调整为“用例收集”“接口测试”。
- 失败/跳过用例来源、质量观测提示和收集清单警告同步使用通用名称。
- Jenkins 邮件中的 Smoke 行和执行画像同步改为“用例收集”“接口测试”。
- README、测试规范和 Jenkins 迁移说明同步报告术语。

## 不变内容

- Jenkins 参数名、默认值、阶段执行逻辑和产物文件名不变。
- `pipeline_reporting` 内部兼容字段及 Quality 数据来源不变。
- 真实接口费用边界不变，未执行真实付费接口。
