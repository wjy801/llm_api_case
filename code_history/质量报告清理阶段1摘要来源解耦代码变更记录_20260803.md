# 质量报告清理阶段 1 摘要来源解耦代码变更记录

## 变更日期

2026-08-03

## 阶段目标

解除 `pipeline-summary.md` 对旧 P0 `summary.json` 的运行时依赖，在删除 P0/P1 报告前建立独立可信的数据来源契约。

## 代码改动

- 核心事实有效性改为校验 `run.json + merged/manifest.json`。
- 校验 run_id、Schema、manifest version、提交状态、完整性状态和哈希集合。
- 请求指标加载前校验 merged manifest 中的 SHA-256。
- Metrics 改为同时校验 manifest、run-metrics、版本、状态和 SHA-256。
- Flaky 改为校验 run_id、Schema、状态及报告使用的列表字段。
- 接口测试未启用时不读取 Quality 目录，避免旧产物污染其他构建模式。
- `quality_available` 更名为 `quality_facts_available`。
- 质量阶段文案改为“运行身份与归并事实完整”。

## 测试改动

- 基线 fixture 不再向运行目录复制 `summary.json`。
- 增加 manifest run_id、状态、Schema 异常测试。
- 增加请求指标哈希错误的章节级降级测试。
- 增加 Metrics run_id/哈希错误测试。
- 增加 Flaky run_id/Schema/状态错误测试。
- 增加非接口测试模式不读取旧 Quality 产物测试。

## 边界

- 尚未删除 P0/P1 模块。
- 请求成功率、重试挽救率、耗时 Top 和 Flaky 口径不变。
- 未执行真实付费接口。
