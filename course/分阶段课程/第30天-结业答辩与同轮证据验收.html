课程大纲

WEEK 6 · DAY 30

结业答辩与同轮证据验收

在一次连续PowerShell会话中生成Runner、JUnit、Allure、Quality与Pipeline Summary，并用run_id、execution_id、Manifest、来源状态和时间证明它们来自同一轮离线执行。

建议时长 3～4 小时Unique run_idQuality ONFlaky OFFMarkdown + JSON
结业证据：Day29实现答辩 + 同轮机器证据包 + 第6周/全课程六维终评；不要求新增功能或全部测试全绿。

01 · Question

“文件都存在”为什么仍不能证明同一轮

reports可能残留旧run、旧Manifest或旧execution-result；只看测试通过也无法证明Quality和Reporting消费了本轮事实。结业验收必须先隔离历史产物，再显式绑定唯一身份。

边界：不制造失败、不新增功能；Flaky默认关闭；真实Smoke禁止执行，Smoke只做collect-only；实际Runner目标固定为离线模块。

02 · Contract

五类身份与来源必须互相吻合

证据必须核对
Runnertarget、planned nodeids、pool stage_id、final_exit_code。
Quality P0run.json与merged Manifest的run_id、status、integrity和expected_execution_ids。
Semantic/Metrics各Manifest的run_id、complete状态及对上游证据的引用。
ReportingQuality阶段为PASSED且没有身份不一致warning；Markdown与JSON共享结论。
时间核心文件更新时间位于本轮开始之后，不能回填历史产物。

03 · Flow

同轮验收是一条不可跳步的链

记录工作树→备份reports/allure→安全清理→唯一run_id→Quality全链开启→Smoke collect-only→离线Runner→更新阶段→生成MD+JSON→核对并留存→恢复原产物

04 · Cleanup

只清理两个经绝对路径校验的可再生产物目录

脚本把reports与allure-results解析为仓库内绝对路径，并同时校验目录叶名称；先复制到系统临时备份目录，再删除并重建。finally无论成功或失败都会恢复原目录和进程环境变量。

禁止：不得用通配符递归删除仓库根目录，不得先跨shell枚举再删除，不得在未备份时清空本地产物。

05 · Identity

父run_id显式设置，execution_id由Runner阶段派生

父身份

QUALITY_RUN_ID=day30-时间-Guid，所有Quality Manifest必须一致。

执行身份

串行Runner使用serial-pool，同时出现在execution-result与P0 expected_execution_ids。

能力开关

显式设置QUALITY、SEMANTIC和METRICS为TRUE。

Flaky

history/state均为FALSE，并移除进程级DB路径。

06 · Execution

Smoke只收集，实际执行目标是离线模块

先运行run_master.py module/smoke --collect-only并保存收集输出；随后用Runner执行module/offline_framework_example，输出smoke-tests.xml、allure-results、execution-result.json和完整Quality目录。

命名说明：Reporting合同把被验证的接口阶段命名为real_smoke；本地验收仅复用该阶段槽位，SMOKE_TARGET明确是离线模块，没有真实外部请求。

07 · Reporting

阶段状态先初始化，再按真实退出码更新

initialize-stages声明framework=false、collect=true、real-smoke=true；collect和离线Runner开始前为NO_DATA，结束后按退出码更新PASSED/FAILED。最后在同一环境中调用generate，同时写出Markdown与机器JSON。

initialize→set collect→set real_smoke→generate MD+generate JSON

08 · Verification

核对身份、提交状态、来源状态和时间

  1. 四个Quality文件的run_id都等于本轮唯一值。
  2. P0 expected_execution_ids与Runner pool stage_id都为serial-pool。
  3. P0与Semantic status为complete，Metrics write_status为complete。
  4. Pipeline JSON中的质量观测阶段为PASSED，warnings不含run_id不一致。
  5. JUnit、execution-result、四个Manifest、Markdown与JSON均在本轮开始后写入。

Reporting的公开Report不重复暴露quality_run_id；它通过成功加载相同run.json与P0 Manifest后把质量阶段标记为PASSED，因此身份原件仍以Quality文件为准。

09 · One-session practice

在仓库根目录执行完整PowerShell流程


$ErrorActionPreference = 'Stop'
$RepoRoot = (Resolve-Path '.').Path
$WorktreeBefore = (& git status --short) -join [Environment]::NewLine
$Python = Join-Path $RepoRoot '.venv\Scripts\python.exe'
if (!(Test-Path -LiteralPath $Python -PathType Leaf)) { throw ('Python不存在：' + $Python) }
$Reports = Join-Path $RepoRoot 'reports'
$Allure = Join-Path $RepoRoot 'allure-results'
$Quality = Join-Path $Reports 'quality'
$StageFile = Join-Path $Reports 'pipeline-stage-status.json'
$BackupRoot = Join-Path ([IO.Path]::GetTempPath()) ('llm-api-case-day30-backup-' + [guid]::NewGuid().ToString('N'))
$RunId = 'day30-' + [DateTime]::UtcNow.ToString('yyyyMMddTHHmmssZ') + '-' + [guid]::NewGuid().ToString('N').Substring(0, 8)
$EvidenceRoot = Join-Path ([IO.Path]::GetTempPath()) 'llm-api-case-day30-evidence'
$EvidenceDir = Join-Path $EvidenceRoot $RunId
$StartedAtUtc = [DateTime]::UtcNow
function Remove-WorkspaceArtifact([string]$Path, [string]$ExpectedLeaf) {
  $full = [IO.Path]::GetFullPath($Path)
  $prefix = $RepoRoot + [IO.Path]::DirectorySeparatorChar
  if (!$full.StartsWith($prefix, [StringComparison]::OrdinalIgnoreCase)) { throw ('拒绝删除仓库外路径：' + $full) }
  if ([IO.Path]::GetFileName($full) -ne $ExpectedLeaf) { throw ('拒绝删除非预期目录：' + $full) }
  if (Test-Path -LiteralPath $full) { Remove-Item -LiteralPath $full -Recurse -Force }
}

$EnvNames = @(
  'QUALITY_ENABLE','QUALITY_SEMANTIC_ENABLE','QUALITY_METRICS_ENABLE',
  'QUALITY_FLAKY_HISTORY_ENABLE','QUALITY_FLAKY_STATE_ENABLE','QUALITY_FLAKY_DB_PATH',
  'QUALITY_RUN_ID','QUALITY_EXECUTION_ID','QUALITY_OUTPUT_DIR',
  'GENERATE_ALLURE_REPORT','GENERATE_HISTORY_REPORT','GENERATE_PIPELINE_SUMMARY',
  'RUN_FRAMEWORK_TESTS','RUN_COLLECT_ONLY','RUN_REAL_SMOKE','PIPELINE_BUILD_RESULT',
  'USE_CHINA_ENVIRONMENT','SMOKE_TARGET','TEST_PARALLEL_WORKERS'
)
$PreviousEnv = @{}
foreach ($name in $EnvNames) { $PreviousEnv[$name] = [Environment]::GetEnvironmentVariable($name, 'Process') }
$HadReports = Test-Path -LiteralPath $Reports
$HadAllure = Test-Path -LiteralPath $Allure
New-Item -ItemType Directory -Path $BackupRoot -Force | Out-Null
if ($HadReports) { Copy-Item -LiteralPath $Reports -Destination (Join-Path $BackupRoot 'reports') -Recurse }
if ($HadAllure) { Copy-Item -LiteralPath $Allure -Destination (Join-Path $BackupRoot 'allure-results') -Recurse }

try {
  Remove-WorkspaceArtifact $Reports 'reports'
  Remove-WorkspaceArtifact $Allure 'allure-results'
  New-Item -ItemType Directory -Path $Reports -Force | Out-Null
  $settings = @{
    QUALITY_ENABLE='TRUE'; QUALITY_SEMANTIC_ENABLE='TRUE'; QUALITY_METRICS_ENABLE='TRUE'
    QUALITY_FLAKY_HISTORY_ENABLE='FALSE'; QUALITY_FLAKY_STATE_ENABLE='FALSE'
    QUALITY_RUN_ID=$RunId; QUALITY_OUTPUT_DIR=$Quality
    GENERATE_ALLURE_REPORT='FALSE'; GENERATE_HISTORY_REPORT='FALSE'
    GENERATE_PIPELINE_SUMMARY='true'; RUN_FRAMEWORK_TESTS='false'
    RUN_COLLECT_ONLY='true'; RUN_REAL_SMOKE='true'
    USE_CHINA_ENVIRONMENT='TRUE'; SMOKE_TARGET='module/offline_framework_example'
    TEST_PARALLEL_WORKERS='off'
  }
  foreach ($item in $settings.GetEnumerator()) {
    [Environment]::SetEnvironmentVariable($item.Key, [string]$item.Value, 'Process')
  }
  [Environment]::SetEnvironmentVariable('QUALITY_EXECUTION_ID', $null, 'Process')
  [Environment]::SetEnvironmentVariable('QUALITY_FLAKY_DB_PATH', $null, 'Process')

  & $Python -m pipeline_reporting initialize-stages --path $StageFile --framework-tests false --smoke-collect true --real-smoke true
  if ($LASTEXITCODE -ne 0) { throw 'initialize-stages失败' }
  & $Python -m pipeline_reporting set-stage --path $StageFile --name smoke_collect --status NO_DATA
  if ($LASTEXITCODE -ne 0) { throw '初始化smoke_collect失败' }
  & $Python -m pipeline_reporting set-stage --path $StageFile --name real_smoke --status NO_DATA
  if ($LASTEXITCODE -ne 0) { throw '初始化real_smoke失败' }

  $CollectOutput = & $Python run_master.py module/smoke --collect-only -q 2>&1
  $CollectExit = $LASTEXITCODE
  $CollectOutput | ForEach-Object { Write-Host $_ }
  $CollectOutput | Set-Content -LiteralPath (Join-Path $Reports 'smoke-collect.txt') -Encoding UTF8
  $CollectStatus = if ($CollectExit -eq 0) { 'PASSED' } else { 'FAILED' }
  & $Python -m pipeline_reporting set-stage --path $StageFile --name smoke_collect --status $CollectStatus
  if ($LASTEXITCODE -ne 0) { throw '更新smoke_collect失败' }

  $RunnerTarget = 'module/offline_framework_example'
  & $Python run_master.py $RunnerTarget --junitxml=reports/smoke-tests.xml --alluredir=allure-results -q
  $RunnerExit = $LASTEXITCODE
  $RunnerStatus = if ($RunnerExit -eq 0) { 'PASSED' } else { 'FAILED' }
  & $Python -m pipeline_reporting set-stage --path $StageFile --name real_smoke --status $RunnerStatus
  if ($LASTEXITCODE -ne 0) { throw '更新real_smoke失败' }
  $BuildResult = if ($RunnerExit -eq 0 -and $CollectExit -eq 0) { 'SUCCESS' } else { 'FAILURE' }
  [Environment]::SetEnvironmentVariable('PIPELINE_BUILD_RESULT', $BuildResult, 'Process')
  & $Python -m pipeline_reporting generate --workspace $RepoRoot --output reports/pipeline-summary.md --machine-output reports/pipeline-summary.json --dotenv .env
  if ($LASTEXITCODE -ne 0) { throw 'pipeline_reporting generate失败' }

  $RequiredFiles = @(
    'reports/smoke-tests.xml','reports/execution-result.json','reports/quality/run.json',
    'reports/quality/merged/manifest.json','reports/quality/semantic/merged/manifest.json',
    'reports/quality/metrics/manifest.json','reports/pipeline-summary.md','reports/pipeline-summary.json'
  ) | ForEach-Object { Join-Path $RepoRoot $_ }
  $Missing = @($RequiredFiles | Where-Object { !(Test-Path -LiteralPath $_ -PathType Leaf) })
  if ($Missing.Count) { throw ('缺少本轮产物：' + ($Missing -join ', ')) }
  if (!(Test-Path -LiteralPath $Allure -PathType Container) -or !(Get-ChildItem -LiteralPath $Allure -Recurse -File | Select-Object -First 1)) {
    throw 'Allure raw产物缺失'
  }
  $Run = Get-Content -LiteralPath (Join-Path $Quality 'run.json') -Raw -Encoding UTF8 | ConvertFrom-Json
  $P0 = Get-Content -LiteralPath (Join-Path $Quality 'merged\manifest.json') -Raw -Encoding UTF8 | ConvertFrom-Json
  $Semantic = Get-Content -LiteralPath (Join-Path $Quality 'semantic\merged\manifest.json') -Raw -Encoding UTF8 | ConvertFrom-Json
  $Metrics = Get-Content -LiteralPath (Join-Path $Quality 'metrics\manifest.json') -Raw -Encoding UTF8 | ConvertFrom-Json
  $Execution = Get-Content -LiteralPath (Join-Path $Reports 'execution-result.json') -Raw -Encoding UTF8 | ConvertFrom-Json
  $Report = Get-Content -LiteralPath (Join-Path $Reports 'pipeline-summary.json') -Raw -Encoding UTF8 | ConvertFrom-Json

  $Ids = @($Run.run_id, $P0.run_id, $Semantic.run_id, $Metrics.run_id)
  if (($Ids | Select-Object -Unique).Count -ne 1 -or $Ids[0] -ne $RunId) {
    throw ('Quality run_id不一致：' + ($Ids -join ', '))
  }
  $ExecutionIds = @($Execution.pool_results | Where-Object { $_.status -ne 'NOT_RUN' } | ForEach-Object { $_.stage_id })
  if (($ExecutionIds -join ',') -ne 'serial-pool' -or (@($P0.expected_execution_ids) -join ',') -ne 'serial-pool') {
    throw 'Runner与P0 execution_id不一致'
  }
  if ($P0.status -ne 'complete' -or $Semantic.status -ne 'complete' -or $Metrics.write_status -ne 'complete') {
    throw 'Quality Manifest尚未完整提交'
  }
  $QualityStage = @($Report.stages | Where-Object { $_.name -eq '质量观测' })
  if ($QualityStage.Count -ne 1 -or $QualityStage[0].status -ne 'PASSED') {
    throw 'Reporting未接受本轮Quality核心来源'
  }
  if (@($Report.warnings | Where-Object { $_ -match 'run_id.*不一致' }).Count) {
    throw 'Reporting存在run_id不一致警告'
  }
  foreach ($file in $RequiredFiles) {
    if ((Get-Item -LiteralPath $file).LastWriteTimeUtc -lt $StartedAtUtc.AddSeconds(-2)) {
      throw ('文件时间早于本轮：' + $file)
    }
  }

  [xml]$JUnit = Get-Content -LiteralPath (Join-Path $Reports 'smoke-tests.xml') -Raw -Encoding UTF8
  $Suites = @($JUnit.testsuites.testsuite)
  $Total = [int](($Suites | Measure-Object -Property tests -Sum).Sum)
  $Failed = [int](($Suites | Measure-Object -Property failures -Sum).Sum)
  $Errors = [int](($Suites | Measure-Object -Property errors -Sum).Sum)
  $Skipped = [int](($Suites | Measure-Object -Property skipped -Sum).Sum)
  $FinishedAtUtc = [DateTime]::UtcNow

  New-Item -ItemType Directory -Path $EvidenceDir -Force | Out-Null
  [ordered]@{
    run_id=$RunId; started_at=$StartedAtUtc.ToString('o'); finished_at=$FinishedAtUtc.ToString('o')
    collect_exit_code=$CollectExit; runner_exit_code=$RunnerExit; pipeline_conclusion=$Report.conclusion
    tests=$Total; passed=($Total-$Failed-$Errors-$Skipped); failed=$Failed; errors=$Errors; skipped=$Skipped
    worktree_before=$WorktreeBefore
  } | ConvertTo-Json -Depth 6 | Set-Content -LiteralPath (Join-Path $EvidenceDir 'verification.json') -Encoding UTF8
  Copy-Item -LiteralPath $Reports -Destination (Join-Path $EvidenceDir 'reports') -Recurse
  Copy-Item -LiteralPath $Allure -Destination (Join-Path $EvidenceDir 'allure-results') -Recurse
  Write-Host ('同轮证据已保存：' + $EvidenceDir)
}
finally {
  Remove-WorkspaceArtifact $Reports 'reports'
  Remove-WorkspaceArtifact $Allure 'allure-results'
  if ($HadReports) { Copy-Item -LiteralPath (Join-Path $BackupRoot 'reports') -Destination $Reports -Recurse }
  if ($HadAllure) { Copy-Item -LiteralPath (Join-Path $BackupRoot 'allure-results') -Destination $Allure -Recurse }
  foreach ($name in $EnvNames) { [Environment]::SetEnvironmentVariable($name, $PreviousEnv[$name], 'Process') }
  Remove-Item -LiteralPath $BackupRoot -Recurse -Force -ErrorAction SilentlyContinue
}
Write-Host ('答辩使用的证据目录：' + $EvidenceDir)

10 · Defense package

答辩提交六组材料

答辩重点：不是声称“全部通过”，而是准确解释本轮事实、已知失败归属、证据身份和各层职责。

11 · Week 6 and course review

第6周复盘与全课程六维最终评分

第6周可信链

Day26分层信任 → Day27统一Report → Day28 CI发布边界 → Day29跨层追踪 → Day30同轮验收。

全课程主线

合同与配置驱动请求行为，Runner固定执行身份，Quality建立事实/关系/指标，Reporting与CI只消费和发布证据。

复盘原则

最终分数不是印象分；每个2分都必须能指向本轮文件、命令、身份或口头因果链。

统一评分维度0分1分2分
源码定位无法找到入口可按材料定位能从离线nodeid独立追踪到Runner、Quality、Reporting和CI入口
调用链与状态只能复述名词能说明主路径能解释请求、执行、归并、报告和发布的分支与终态
所有权职责互相覆盖知道主要分工能说明对象、资源、领域规则和CI动作的唯一所有者
证据映射只报绿/红能展示部分产物能证明JUnit、Allure、Quality和Summary分别回答的问题及同轮身份
设计边界无法说明选择原因能复述当前设计能比较Hash/签名、Polling/推送和分层事实/单一报告的适用条件
迁移能力只能填写原模板能在提示下迁移能把全链追踪和同轮验收独立迁移到另一个现有离线场景

12 · Design choice

设计选择与适用边界

现方案在一次连续、隔离的PowerShell会话中生成Runner、Quality与Reporting证据，并用身份、提交状态和时间证明同轮。
替代方案拼接此前成功运行的文件、截图和手工说明，或只以最终测试退出码作为结业证据。
选择理由同一会话减少环境漂移；唯一run_id、execution_id和写入时间构成可复查证据，已知失败也能被准确归属而非隐藏。
不适用条件生产发布验收、法规审计或跨组织交付通常还要求签名来源、独立审批、受控环境与长期留存，本地同轮证据不能替代这些保证。
